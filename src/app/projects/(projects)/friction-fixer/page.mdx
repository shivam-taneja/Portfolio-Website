    # Friction Fixer

    <SubSection title="About The Project">
      Friction Fixer is an AI agent that works on a website by itself. It looks at how visitors behave, changes the page to fix what is driving them away, then checks whether the change helped. If it did not, the agent undoes the change and the next run can try something else.

      Someone still starts each run. The agent does not loop forever on its own.
    </SubSection>

    <SubSection title="How It Works">
      - **Analyst** reads the visitor numbers, past verdicts, and the files it asks for, then writes one plan.
      - **Builder** edits the project's source, commits, and opens a pull request with the GitHub App. The pull request is merged. If it conflicts, the run waits until you resolve it on GitHub and press Continue.
      - **Reviewer** compares before and after. Bounce rate has to fall by at least 5 percentage points to keep the change. Otherwise a second pull request undoes it and is merged too.

      Live numbers come from the PostHog project for the same site the repository deploys. The check wait is set in Settings, from 1 hour up to 14 days, and defaults to 7 days.
    </SubSection>

    <SubSection title="Features">
      - **One change at a time**: Each run ships a single plan, not a pile of edits
      - **GitHub pull requests**: The site changes through a pull request you can read
      - **Measured, then kept or undone**: Bounce rate decides. Scroll, time on page, and pageviews are recorded and do not decide
      - **Same site, same numbers**: PostHog and the repository have to be the site that is actually deployed
      - **Your wait**: The check window is yours, from 1 hour to 14 days
