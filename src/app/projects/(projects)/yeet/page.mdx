    <SubSection title="About The Project">
      Yeet carries your posts between X and Threads automatically. Type it in one place, and it lands in the other — same moment, no copy-paste.

      It is a Chrome extension that runs in the browser. When you compose a post on X or Threads, it captures the text and submits it to the other platform in the background, using the session you are already logged into. There is no database. Nothing about the post is saved.
    </SubSection>

    <SubSection title="How It Works">
      - Post on X, and it lands on Threads. Post on Threads, and it lands on X.
      - Yeet uses the accounts you are already logged into. It never asks for passwords or stores login tokens.
      - You can pause a direction and see what landed without leaving the page you are on.
    </SubSection>

      - **Two-way by default**: X to Threads and Threads to X
      - **Write once**: The same words land on both timelines
      - **No copy-paste**: No re-typing and no second post to remember
      - **Runs locally**: No server, no stored posts
